Политика конфиденциальности

Mind Balance - Ваш помощник в заботе о ментальном здоровье

1. Введение

MindBalance серьезно относится к защите вашей конфиденциальности. Эта Политика описывает, как мы собираем, используем и защищаем ваши данные.

2. Собираемая информация

  • Учетные данные Google (имя, email, ID) для аутентификации
  • Данные о психическом здоровье (настроение, тесты, дневник)
  • Данные об использовании приложения
  • Техническая информация

3. Правовые основания

Обработка данных осуществляется на основе:

  • Вашего явного согласия
  • Выполнения договорных обязательств
  • Законных интересов

4. Использование данных Google API

Мы используем Google API Services в строгом соответствии с политиками Google:

  • Используем данные только для предоставления функций приложения
  • Не передаем данные третьим сторонам
  • Не используем данные для рекламы
  • Обеспечиваем безопасное хранение

5. Ваши права

Вы имеете право:

  • Доступа к вашим данным
  • Исправления неточностей
  • Удаления данных
  • Переносимости данных
  • Отзыва согласия

6. Безопасность

  • Все данные шифруются на устройстве
  • Используется защищенная передача данных
  • Локальное хранение с возможностью экспорта

7. Сроки хранения

Данные хранятся до удаления аккаунта пользователем.

8. Контакты

По вопросам защиты данных: mindbalancekz@gmail.com

1. Кіріспе

MindBalance сіздің құпиялылығыңызды қорғауға баса назар аударады.

2. Жиналатын ақпарат

  • Google тіркелгі деректері (аты, email, ID)
  • Психикалық денсаулық деректері
  • Қолданбаны пайдалану деректері
  • Техникалық ақпарат

3. Заңды негіздер

Деректерді өңдеу:

  • Сіздің келісіміңізбен
  • Келісімшарттық міндеттемелерді орындау үшін
  • Заңды мүдделер негізінде

4. Google API деректерін пайдалану

Біз Google API Services-ті Google саясатына сәйкес пайдаланамыз:

  • Деректерді тек қолданба мүмкіндіктерін ұсыну үшін пайдаланамыз
  • Деректерді үшінші тұлғаларға бермейміз
  • Жарнама үшін пайдаланбаймыз
  • Қауіпсіз сақтауды қамтамасыз етеміз

5. Сіздің құқықтарыңыз

Сізде келесі құқықтар бар:

  • Деректерге қол жеткізу
  • Қателерді түзету
  • Деректерді жою
  • Деректерді көшіру
  • Келісімді кері тарту

6. Қауіпсіздік

  • Барлық деректер құрылғыда шифрланады
  • Қауіпсіз деректер тасымалдауы
  • Жергілікті сақтау экспорттау мүмкіндігімен

7. Сақтау мерзімдері

Деректер пайдаланушы есептік жазбасын жойғанға дейін сақталады.

8. Байланыс

Деректерді қорғау бойынша сұрақтар үшін: mindbalancekz@gmail.com
